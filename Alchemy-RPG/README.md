
# Alchemist RPG

Консольна RPG-гра на Python.

## Сюжет
Гравець виступає в ролі алхіміка.
Він збирає інгредієнти, створює зілля
та продає їх за золото.

## Можливості
- Система інвентаря.
- Збирання інгредієнтів.
- Створення зіль.
- Продаж зіль.
- Система ігрових днів.
- Перемога та поразка.

## Мета гри
Заробити 10000 золотих.

## Запуск
Відкрити термінал та виконати:

python main.py

## Мова програмування
Python
